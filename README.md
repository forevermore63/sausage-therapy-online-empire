## Deploy

This is a pure static site. Deploy to Vercel, Netlify, or any static host in seconds.

```bash
# From this folder
npx vercel --prod
```

Or connect the GitHub repo `forevermore63/sausage-therapy-online-empire` to Vercel for continuous deployment.
